# TYMotors — Audit des images du configurateur

Date : 25 août 2026  
Environnement ciblé : staging / Preview uniquement  
Source de vérité : 14 générations actives dans Supabase.

Toutes les compositions finales ont été contrôlées en vue trois-quarts avant,
avec le véhicule complet, un canevas 16:9 (1672 × 941), le studio noir/rouge
TYMotors, sans personne, texte promotionnel ni watermark. Les variantes sont
servies par Cloudinary avec `f_auto,q_auto,c_fill,g_auto` en 1600×900,
1200×675 et 800×450. Les sources restent séparées des rendus finaux.

Les hotspots `Calandre` et `Habitacle / CarPlay` sont positionnés par génération.
L'API les masque tant qu'aucun produit actif ne possède une compatibilité exacte
et vérifiée pour cette génération ; elle n'invente donc aucune recommandation.
